# Skillrise – HR training platform

Open this folder in VS Code and run `index.html` with Live Server.

| Page | HTML | CSS | JS |
|---|---|---|---|
| Classic | index.html | css/home1.css | js/home1.js |
| Premium | premium.html | css/home2.css | js/home2.js |
| Programs | programs.html | css/inner.css | js/programs.js |
| Trainers | trainers.html | css/inner.css | js/trainers.js |
| Case Studies | case-studies.html | css/inner.css | js/case-studies.js |
| Login | login.html | css/inner.css, css/login.css | js/login.js |
| HR Dashboard | dashboard.html | css/inner.css, css/dashboard.css | js/dashboard.js |

Shared: `css/base.css` (header, footer, colors, shared animations), `js/common.js` (dark mode, RTL, menu, scroll reveal, count-up), `js/data.js` (sample programs, employees, trainers, case studies).
The login accepts any email and a 4+ character password (demo). The dashboard keeps its data in memory only; connect a backend to make it real.

Photos live in `assets/img/`. `skillrise-hero.jpg` is used as the social-share preview image.
